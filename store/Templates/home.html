Twamev Architecture — Folder Structure, VS Code & Django + MySQL Guide

Complete production roadmap for converting this frontend into a multi-file Django + MySQL e-commerce platform

1. Recommended Project Folder Structure (Frontend & Django Ready)

When organizing your files in VS Code for standalone frontend testing and subsequent Django template integration, structure your workspace as follows:

twamev_ecommerce/
├── manage.py
├── requirements.txt                  # django, mysqlclient, razorpay, pillow, python-dotenv
├── twamev_project/                   # Main Django Project Config
│   ├── __init__.py
│   ├── settings.py                   # MySQL DB config, STATICFILES_DIRS, MEDIA_ROOT
│   ├── urls.py                       # Main URL router
│   └── wsgi.py
├── store/                            # Core E-Commerce App
│   ├── models.py                     # Category, Product, Order, OrderItem, ContactEnquiry
│   ├── views.py                      # Template views + /api/orders/ & /contact/ endpoints
│   ├── urls.py                       # App-level routes
│   └── admin.py                      # Custom Django Admin for inventory & order status
├── templates/                        # Separated HTML files (Django Template Ready)
│   ├── base.html                     # Shared Navbar, Announcement Bar, Footer, CSRF script
│   ├── home.html                     # Hero, Featured Categories, Bestsellers, Reviews

2. Running the Frontend Locally in VS Code (Stage 1)

  1. Open Visual Studio Code and create a new folder named twamev-store.
  2. Save this file as index.html (or split the CSS into static/css/styles.css and JS into static/js/app.js).
  3. Install the Live Server extension by Ritwick Dey in VS Code.
  4. Right-click index.html and click "Open with Live Server" (runs at http://127.0.0.1:5500).
  5. Test adding items to the cart, applying coupons (TWAMEV10 / DIVINE20), and toggling between Frontend Demo Mode and Django API Mode on the Checkout page.

# store/models.py
from django.db import models

class Category(models.Model):
    name = models.CharField(max_length=120, unique=True)
    slug = models.SlugField(unique=True)
    description = models.TextField(blank=True)

class Product(models.Model):
    category = models.ForeignKey(Category, on_delete=models.CASCADE, related_name='products')
    sku = models.CharField(max_length=40, unique=True)
    name = models.CharField(max_length=200)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    original_price = models.DecimalField(max_digits=10, decimal_places=2)
    stock = models.PositiveIntegerField(default=25)
    is_bestseller = models.BooleanField(default=False)
    is_new_arrival = models.BooleanField(default=False)
    description = models.TextField()
    image_url = models.URLField(max_length=500)

class Order(models.Model):
    STATUS_CHOICES = [
        ('PENDING', 'Pending Verification'),
        ('CONFIRMED', 'Confirmed & Sanctifying'),
        ('SHIPPED', 'Dispatched via Courier'),
        ('DELIVERED', 'Delivered')
    ]
    order_number = models.CharField(max_length=32, unique=True)
    full_name = models.CharField(max_length=120)
    phone = models.CharField(max_length=15)
    email = models.EmailField()
    street_address = models.TextField()
    city = models.CharField(max_length=80)
    state = models.CharField(max_length=80)
    pincode = models.CharField(max_length=10)
    payment_method = models.CharField(max_length=30) # COD or RAZORPAY_ONLINE
    subtotal = models.DecimalField(max_digits=10, decimal_places=2)
    discount = models.DecimalField(max_digits=10, decimal_places=2, default=0)
    delivery_charge = models.DecimalField(max_digits=10, decimal_places=2, default=0)
    total_amount = models.DecimalField(max_digits=10, decimal_places=2)
    status = models.CharField(max_length=20, choices=STATUS_CHOICES, default='PENDING')
    created_at = models.DateTimeField(auto_now_add=True)

class ContactEnquiry(models.Model):
    name = models.CharField(max_length=120)
    phone = models.CharField(max_length=15)
    email = models.EmailField()
    subject = models.CharField(max_length=150)
    message = models.TextField()
    submitted_at = models.DateTimeField(auto_now_add=True)
